# CodeAlpha Hangman Game

## Project Description
This is a simple text-based Hangman Game developed using Python.  
The player has to guess the hidden word one letter at a time before the attempts are finished.

## Features
- Random word selection
- Limited number of attempts
- Displays correct guesses
- Beginner-friendly Python project

## Technologies Used
- Python

## Concepts Used
- random module
- loops
- if-else conditions
- lists
- strings
- user input

## How to Run
1. Open terminal
2. Run the following command:

```bash
python hangman.py
```
